## 🌟 Portfolio Overview

This repo is the source for my personal portfolio site — built to give recruiters and collaborators one place to see my experience, skills, and shipped work.

- 🎬 Animated hero with a typing headline and live stat counters
- 🌈 A distinct, colorful visual identity — no default Bootstrap look
- 🧭 Scroll-spy navigation and reveal-on-scroll animations throughout
- 🪄 3D tilt on the profile photo and project cards
- 📱 Fully responsive, right down to a working mobile nav menu
- 📬 Direct links to my email, phone, LinkedIn, GitHub, and LeetCode

## 🔧 Running Locally

```bash
# 1. Clone this repository
git clone https://github.com/Jayaram5685/Portfolio.git

# 2. Navigate into the project directory
cd Portfolio

# 3. Serve it locally (recommended over opening the file directly)
python -m http.server 5500
# — or —
npx serve .
```

Then open **`http://localhost:5500`** in your browser. 🎉

## 🎛️ Customizing

- 🎨 **Colors** — all defined as CSS variables at the top of `styles.css` (`--c1` … `--c5`, `--accent`, `--bg`)
- ✍️ **Content** — lives directly in `index.html`, no CMS or data file
- ⌨️ **Typing headline** — edit the `phrases` array near the top of `script.js`
- 🖼️ **Résumé / photo** — swap in your own files with the same names, or update the paths in `index.html`
